## Layers and gates

| Layer | Environment/coverage | Gate |
|---|---|---|
| L0 | Offline candidate package, manifest, lock inventory, per-component license/source materials, bilingual docs | Missing files, hashes or obligations block delivery |
| L1 | Portable pure core, no OS headers | Deterministic COM/arguments/quoting model/state machine |
| L2 | Fake OS/terminal/process/identity/clock | Fault injection and leak-free lifecycle |
| L3 | Real Windows host, normal privileges, installation/enable and JSON-RPC | **Mandatory for functional completion**; evidence for processes/ui, Job and stdio |
| L4 | Unlocked desktop, physical keyboard/mouse, real serial/target hardware and control-line instruments | **First-delivery gate**; actual keyboard/TTY, DTR/RTS, hotplug safety and cleanup |
| L5 | Clean Windows without MSYS2/developer PATH, locked candidate package | Closure, calibrated performance, compliance/distribution; failure blocks release |

External terminal and mintty are candidates to decide through separate probes; promise only passing backends. No eligible backend means blocked. Missing serial hardware, line instruments, screen reader or clean machines remains blocked/not executed; fake tests, process startup or wireframes cannot count as passing evidence. L3 does not replace L4. Explicitly exclude deferred P2 integration from delivery.

## Evidence and exit criteria

Future evidence belongs in `tio-<date>/`, recording case/requirement IDs, design sections, expected/actual outcomes, results, environment versions/commits, hardware, parameters, permissions and untested boundaries. DTR/RTS needs actual waveforms and wiring conditions; UI screenshots cannot prove electrical levels. Selected repository evidence follows the workbench 鈮?MB budget; link large originals externally and redact logs. No evidence artifacts are created now.

Delivery requires evidence for all P0/P1 cases, passing L3/L4, closed per-component obligations and no unresolved failures. L5 failure blocks release. Unmeasured candidate interaction-latency targets: cached-query p95 100 ms, Launch click to interactive p95 2 s, owned-tree stop 2 s. Calibrate working-set budgets only after deriving them from measured baseline, peak and justified headroom in design 搂9, without a preset cap; separate processes and report overall session peak. Choose sampling counts from coverage, variability and statistical precision, reporting counts and uncertainty. After implementation update actual/untested outcomes and design section 11. Every current status remains not executed.
